# Lick 練習庫

吉他 Lick 練習網頁 App：看指板動畫、聽合成吉他聲、調速度跟彈，並用麥克風或錄音介面做節奏測驗。
另有 **🎤 人聲練習**（ACG 歌曲，男生用偽音唱女聲歌）：音高圖 + 麥克風音準 / 節奏評分。

👉 **開啟：https://saitor.github.io/lick/**

## 內容

| 分類 | 說明 |
|---|---|
| 課件 | 看譜圖分析的 Lick |
| 基礎課 | 33 課（空弦、移位、滑音、推弦、搥勾弦、和弦、悶音、泛音、五聲音階、點弦…），每課有「整課」和每 8 小節一段 |
| 動漫歌曲 | 79 首歌的 Lick（孤獨搖滾、BangDream、鬼滅之刃…） |

共 837 個 Lick。

### 🎤 人聲練習（頁面最上面切換，或開 https://saitor.github.io/lick/vocal.html）

| 分類 | 說明 |
|---|---|
| 暖聲練習 | 偽音五音音階、換聲點八度跳、偽音長音、三度跳節奏（從 A3 往上爬） |
| 女聲原曲 | 31 首（16 首有日文歌詞），每首切成一句一句 |
| 男聲原曲 | 4 首（真聲練習） |

共 35 首歌、1283 句。功能：
- **音高圖**：色塊是要唱的音（藍 = 真聲、黃 = 換聲區、粉 = 偽音），下面是歌詞；開麥克風後即時畫出你唱的音高線，唱準變綠色
- **移調**：原調（偽音）／降 3／降 5／降八度（真聲）；**音域測試**唱出最低音、真聲上限、偽音最高後自動建議移調
- **合成人聲示範** + 貝斯根音 + 節拍器，預備拍先給第一個音
- **跟唱評分**：音準（偏高 / 偏低幾音分、唱成哪個音）和節奏（太早 / 太晚進幾毫秒）；「只練節奏」模式每個音唸「嗒」
- **測驗**：連續 N 次 OK 才過關
- 戴有線耳機最好；第一次先按「校正延遲」（耳機：第 5 下開始每下唸「嗒」；喇叭：保持安靜）

## 功能

- **指板動畫 + TAB 譜**：播放時標出每個音在哪條弦、哪一格，並說明節奏、技巧與建議指法
- **速度調整**：直接輸入 BPM、±1 / ±5，或原速 50～100%；播放和測驗共用，每個 Lick 會記住上次的速度
- **測驗模式**：節拍器數 4 拍後跟著彈，判斷漏音、多彈、搶拍 / 拖拍、音高；連續 N 次全對才過關，有練習紀錄、連續天數，可匯出 CSV
- **可離線使用**：加入主畫面後，沒有網路也能開

## iPhone 安裝

1. 用 **Safari** 開上面的網址
2. 按「分享」→「加入主畫面」
3. 之後從主畫面的圖示開啟

## 吉他 USB 直接接 iPhone（最準，例：Donner HUSH X Pro）

吉他有 USB 音訊輸出時，不用音箱、不用錄音介面：

1. 用 **OTG 線**接吉他的 USB-C 和 iPhone（一般充電線不行；Lightning 接頭的 iPhone 用「Lightning 對 USB 3 相機轉接器」）
2. 先把 GarageBand 等錄音 App 完全關掉
3. 測驗模式「來源」選「**錄音介面／USB 直插**」→ 連接 → 允許麥克風；「輸入」選 USB／吉他，「聲道」選「兩個混合」
4. 吉他音量中間左右、音色選乾淨少殘響的；耳機插吉他的 3.5 mm 孔，節拍器從手機喇叭出來
5. 按「**校正延遲**」：從第 5 下開始每下撥一次空弦（共 8 下）

## 用手機麥克風測驗

1. 吉他接音箱，手機放在音箱前 30～50 公分
2. 測驗模式「來源」選「手機／電腦麥克風」，允許使用麥克風
3. **第一次先按「校正延遲」**：
   - 用喇叭聽節拍器：保持安靜，手機會自己錄喇叭的聲音算延遲
   - 戴有線耳機：從第 5 下開始，每下撥一次空弦（共 8 下）
4. 換手機、換耳機 / 喇叭、iOS 更新後要重新校正

> 不建議用藍牙耳機（延遲大且不穩定）。

## 電腦 + 錄音介面

用 Chrome 開網址，測驗模式「來源」選錄音介面、選吉他所在的聲道，同樣先按「校正延遲」。

## 更新

App 會在背景下載新版，**關掉再重開一次**就會套用。
